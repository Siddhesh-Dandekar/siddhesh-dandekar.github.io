# Siddhesh Dandekar's portfolio

This repository publishes the portfolio at [siddhesh-dandekar.github.io](https://siddhesh-dandekar.github.io/). The React application lives in the [portfolio repository](https://github.com/Siddhesh-Dandekar/portfolio).

To publish the latest portfolio changes at the root URL, open **Actions**, select **Deploy portfolio to GitHub Pages**, and choose **Run workflow** on `main` after the changes reach `portfolio/main`. The workflow also runs when this repository's `main` branch changes.
